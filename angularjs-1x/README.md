# AngularJS 1.x Login Demo

This is the **legacy AngularJS 1.8.x** example, separate from the modern Angular example in `angularjs/`. AngularJS 1.x is end-of-life, so use this folder for Web Technology lab practice, not for a new production system.

## Run
`npm install` then `npm start`, and open the local URL printed by Vite. The CDN scripts require internet access.

Fill the placeholders in `config.js` with your Supabase project URL and browser-safe publishable/anon key. The form uses Supabase Auth password sign-in. Never expose a service-role key. Use RLS for database policies.
